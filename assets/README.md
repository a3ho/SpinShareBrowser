# SpinShare Browser artwork

English | [简体中文](README.zh-CN.md)

The app icon combines a magnifying glass with waveform bars, inspired by SpinShare's colors and artwork.

- `spinshare-browser.png`: full-resolution artwork.
- `spinshare-browser-favicon.png`: browser icon.
- `spinshare-browser.ico`: Windows icon.
