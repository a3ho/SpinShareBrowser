### 测试基线
- [ ] `python -m unittest discover -s tests -p "test_*.py"` — 全绿

## 自我审查流程（修复任何 UI 问题时）

1. **修改前**: 从 click → handler → state → DOM → CSS 画全链路（P5）
2. **修改后**: 从用户视角截图验证（P7）
3. **全模式**: 该功能的所有模式截图走查
4. **状态矩阵**: 涉及布局/窗口 → normal + maximized 走查（P2）
5. **测试**: 测试反映新行为
