# 红线清单（违反任何一条 = 不可合并的回归）

## 对 spinsha.re 的礼仪（产品根基）

1. **绝不**调用会 increments 计数的接口：`/api/song/{id}`（详情=浏览量）禁碰；下载只允许用户明确点击后的 `/api/song/{id}/download`（一次）。
2. 查询/筛选/搜索/标签/排序/翻页永远只读本地缓存；联网目录数据只来自 `/api/searchCharts`。
3. 评论 `/api/song/{id}/reviews` 与用户档案/搜索按需、有界（LRU/超时/并发限制）。
4. 音频只走静态 CDN `_0.ogg/_0.mp3` 与静态 SRTB；游戏音频只读直传，绝不复制/转码/分发。

## 冷却与节流（防打服务器）

5. 手动 10 分钟冷却的预约协议顺序不可变（连接后、发请求前落盘）；连接阶段失败/已回滚的 401、403 不占冷却；其余失败全占。
6. 自动通道退避 5m/15m/1h/6h 独立持久；自动不得绕过手动冷却；afterInstall 合并节流。
7. 评论手动刷新 60s 共享冷却，失败也计入。

## 安装与数据安全

8. ZIP 白名单、路径校验、事务两阶段提交、崩溃恢复的身份核对——任何"简化"都是安全回归。
9. 安装器/维护**绝不强杀**有活跃任务的进程；退出以 PID 句柄确认为准。
10. 删除仅限精确匹配；删除/安装互斥（前后端双侧）。
11. 状态/程序/游戏目录三者不得互相嵌套；一切写入原子化且拒绝链接。

## 界面契约（用户可感知）

12. 无原生 title tooltip；图标控件必须有可访问名称。
13. 未知的评论数/安装状态**不得**显示为 0/未安装；失败保留最后确认状态。
14. 浮层/展开不得改变页面高度或推动其它卡片；收起重置滚动。
15. README 的 Use/使用保持任务导向；实现细节只进 CHANGELOG/PRODUCT/DESIGN。
16. 中英文 UI 与文档永远同步改。

## 流程

17. 未经用户同意不 push / 不 dispatch workflow（CI 额度耗尽）。
18. 版本号永不复用；线上只留最新稳定 Release。
19. 覆盖已存在文件前必须先 Read（用户亲自纠正过的错误）。
