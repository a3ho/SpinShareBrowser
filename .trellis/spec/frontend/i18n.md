# i18n 令牌系统

## 机制

- `m(key)` → `'\u0001spinshare-<rand>:text:<索引>\u0002'`（索引 = key 在 locales.json en 键序中的位置）。**不是**返回译文。
- `renderUI(value, language)` 把令牌替换为 `UI_CATALOG[language][key]`；`number()` 令牌替换为 `toLocaleString(language)`。
- DOM 绑定：`uiText(node, value)` / `uiAttr(node, name, value)` 把含令牌的原文存进 `uiBindings` WeakMap 并给节点打 `data-ui-text`/`data-ui-attributes` 标记；`setUILanguage` 只遍历带标记的节点重渲染——**已渲染的用户内容（歌名、评论）永不被翻译触碰**。
- `data-ui-static="key"` / `data-ui-attr-<name>="key"`：index.html 静态结构的绑定入口（setupLanguage 扫描一次）。
- 后端错误本地化：`localizeInstallerMessage` 把后端英文原文（含句号变体）映射回 key；`INSTALLER_MESSAGE_REPLACEMENTS` 取 `engine.` 前缀的键按长度排序做 replaceAll。

## locales.json 规则（后端 validate_catalog 强制）

- 恰好 `en` + `zh-CN` 两键；每语言是**扁平** string→string 字典；两语言键集合必须完全一致；当前 596 键。
- 前端 `UI_KEY_INDEX` 以 en 的键顺序为准——**追加键必须同时加两语言**，改顺序会令所有索引令牌错位（等于换语言版本号）。
- 中文文案的标点风格：程序生成文案不带句末句号、进行中用省略号（DESIGN 规矩，locales 已遵守）。

## 坑

- 任何 `element('div', someText)` 若 someText 可能含令牌，必须走默认路径（element 内部就是 uiText）——别用 innerHTML/textContent 绕过。
- `m()` 传不存在的 key 直接 throw（宁可崩也别显示错文案）。
- 原生侧（desktop.py 托盘/toast/错误框）也读同一 locales.json（load_catalog），另有 `_NOTICE_TEXT` 兜底表。
