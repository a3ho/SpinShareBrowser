# SpinShare Browser

[English](README.md) | **简体中文**

用于浏览、安装和管理本地 [SpinShare](https://spinsha.re/) 谱面的第三方 Windows 工具。

![浏览和管理本地 SpinShare 谱面](docs/images/overview-zh-CN.png)

## 功能

- 按难度和上传日期筛选谱面。
- 在筛选结果内按歌名、副标题、艺人或上传者 / 谱师搜索。
- 独立叠加标签筛选，候选显示追加该标签后的结果数；已选标签栏随滚动吸顶。
- 根据本地核对的安装状态，显示全部谱面、仅已安装或仅未安装的谱面。
- 按上传日期、难度等级、浏览量、下载量或歌名排序。
- 在顶栏唯一的全局播放器中播放谱面的完整歌曲。
- 查看封面、作者说明和标签，按需显示完整评论，下载并安装谱面，识别安装状态并删除已核对的本地谱面。
- 支持简体中文和 English 界面。

## 安装

**[下载 Windows 安装包](https://github.com/a3ho/SpinShareBrowser/releases/latest)**

1. 在发布页的 **Assets** 中下载 `SpinShareBrowser-2.0.1-windows-x64-setup.exe`。源码包供自行构建使用。
2. 运行安装包，按向导完成安装。程序为当前 Windows 用户安装，创建开始菜单入口，并提供桌面快捷方式选项。

需要 **Windows 10 1903 或更高版本、Windows 11（x64）**，以及 **.NET Framework 4.8 或更高版本**。安装包包含 Python 和程序所需的库。

安装包尚未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。请只从本仓库的最新 Release 下载，并使用随附的 `.sha256` 文件核对安装包。

安装程序会复用已有的 **Microsoft Edge WebView2 Runtime 123.0.2420.47 或更高版本**。缺少或版本较旧时，通过随包附带的微软引导程序联网下载安装；下载失败可重试。需要离线安装时，请先安装微软 [Evergreen 独立运行时](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。浏览 SpinShare 需要联网。WebView2 包含 Microsoft Defender SmartScreen，数据处理方式见[微软隐私声明](https://aka.ms/privacy)。

## 使用

### 浏览与查找谱面

1. 选择难度和上传日期，点击“筛选谱面”
2. 使用搜索、标签、安装状态和排序继续缩小范围
3. 通过分页浏览结果，或选择“不限制”后向下滚动加载更多谱面

点击“添加标签”可以组合多个标签，也可以直接点击谱面卡片上的标签。“重置筛选”会恢复默认浏览条件。

![筛选、搜索、安装并管理谱面](docs/images/workflow-zh-CN.gif)

### 播放歌曲

把鼠标移到谱面封面上，点击播放按钮。顶部全局播放器会显示当前歌曲，可暂停、继续播放或拖动进度条。

部分谱面使用游戏内的音乐。试听这些谱面时，请保留通过 Steam 安装的 Spin Rhythm XD 及所需 DLC。

开始播放歌曲后，按 **空格键** 暂停或继续，按 **← / →** 后退或快进 5 秒。输入文字时，这些快捷键不会生效。

### 查看说明与评论

较短的作者说明直接显示在谱面卡片中。内容较长时，点击说明区域查看全文。

点击评论数量即可在浮层中阅读评论。如果希望同时查看所有谱面的评论，可以开启“展开所有评论”。

### 下载、安装与删除

点击谱面卡片上的“下载并安装”。首次使用时，确认谱面安装目录，或点击“修改目录”。

已安装的谱面会显示“已安装”；需要用列表中的版本替换时，点击“重新安装”。DLC 谱面使用相同的安装、重新安装和删除操作，并可通过要求标识打开对应的 Steam 页面。

已安装谱面显示“删除”时，点击后不会再次确认，而是立即永久删除该谱面的自定义谱面、封面和音频文件；其它文件及 Steam DLC 文件不受影响。可以连续点击多个谱面的“删除”并加入队列。

回到程序时会自动刷新安装状态。单首谱面完成后无需等待其它排队任务，对应卡片就会更新。

更新 SpinShare Browser 时，直接运行最新安装包。如果仍有下载或安装任务，请等待任务结束后点击“重试”。

### 数据更新与后台运行

程序会把谱面数据保存在本地并自动同步，大多数情况下无需手动更新。如果列表明显过旧，可以点击“更新数据”。

关闭窗口时可以选择完全退出或继续在系统托盘运行。语言、谱面安装目录和关闭行为都可以在“设置”中修改。

## 升级与卸载

再次运行安装包时，欢迎页会明确说明将以覆盖更新方式替换已安装的 SpinShare Browser 并保留设置；本地已安装谱面不受影响。通过 Windows“设置 → 应用”或控制面板“程序和功能”卸载。卸载会删除工具及其设置、缓存等本地数据，保留下载或安装的谱面以及共享 WebView2 运行时。

程序默认安装到 `%LOCALAPPDATA%\Programs\SpinShareBrowser`，设置和内嵌浏览器数据存放在 `%LOCALAPPDATA%\SpinShareBrowser`，谱面存放在所选游戏目录中。
